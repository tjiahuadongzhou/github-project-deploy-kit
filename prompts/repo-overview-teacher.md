# GitHub 开源项目宏观讲解提示词

请帮我讲解这个 GitHub 开源项目：

项目地址：
<在这里粘贴 GitHub 地址>

请你像老师给小白上课一样讲解。

## 第一阶段：只读分析

要求：

1. 先不要安装依赖
2. 不要运行项目
3. 不要修改任何文件
4. 只阅读 `README`、`docs`、`package.json`、`pyproject.toml`、`pubspec.yaml`、`Cargo.toml`、`go.mod` 等关键文件
5. 如果项目很大，先只读顶层目录和核心说明文件

请使用：

- `codebase-onboarding` skill = 代码库入门
- `code-tour` skill = 代码导览
- `documentation-lookup` skill = 文档查找

## 输出要求

请按下面结构输出：

### 1. 一句话总结这个项目

用一句非常简单的话告诉我：
这个项目到底是干嘛的？

要求：

- 不要用复杂术语
- 不要直接复制 `README`
- 用普通人能听懂的话说

### 2. 这个项目解决了什么问题？

请解释：

- 没有这个项目之前，用户会遇到什么麻烦？
- 这个项目帮用户省了什么时间？
- 它解决的是开发问题、部署问题、设计问题、AI 工具问题，还是其他问题？

### 3. 这个项目适合谁？

请分成：

- 新手适不适合？
- 开发者适不适合？
- 设计师适不适合？
- 公司团队适不适合？
- 个人学习适不适合？

### 4. 这个项目为什么值得看？

请说明：

- 它有什么亮点？
- 它和普通项目有什么不同？
- 它是否适合我借鉴？
- 它是否适合直接使用？

### 5. 宏观架构图

请用文字画出项目结构：

```text
项目名/
├── 目录 A：中文解释
├── 目录 B：中文解释
├── 文件 A：中文解释
└── 文件 B：中文解释
```

### 6. 重要英文词翻译

请列出项目里出现的重要英文词，并翻译成中文。

格式：

| 英文 | 中文 | 小白理解 |
|---|---|---|
| Agent | 智能体 / 代理 | 一个专门干某件事的 AI 小助手 |

要求：

- 每个英文词都要有中文翻译
- 每个词都要有小白解释
- 不要只翻译字面意思

### 7. 我应该怎么学习这个项目？

请给我一个学习顺序：

第一步：先看什么
第二步：再看什么
第三步：动手做什么
第四步：如何部署
第五步：如何二次开发

### 8. 这个项目对我有什么用？

请结合普通开发者视角告诉我：

- 我可以直接用它做什么
- 我可以借鉴它的哪些设计
- 我不应该盲目照搬什么

## 讲解风格要求

- 用中文
- 把我当成小白
- 不要默认我懂专业术语
- 每个英文关键词后面都加中文解释
- 多举生活类比
- 不要一下子讲太深
- 先宏观，再细节
- 如果你不确定某个结论，请明确说不确定
- 不要为了显得专业而堆术语
