# 通用提示词：学习 GitHub 开源项目并输出中文学习笔记

请帮我学习一个 GitHub 开源项目。

项目地址：
<在这里粘贴 GitHub 地址>

目标：
我暂时不想部署它，重点是理解这个项目、学习它的设计和实现思路。

请优先使用以下已安装的 Agent / Skill：

1. `codebase-onboarding` skill：帮助我快速理解这个项目是做什么的
2. `code-tour` skill：讲解目录结构、关键文件和模块关系
3. `documentation-lookup` skill：优先阅读 `README`、`docs`、`examples` 和官方文档，不要凭记忆乱猜

工作要求：

1. 先只读分析
2. 可以 `git clone` 项目用于本地阅读
3. 不要执行安装依赖命令
4. 不要运行构建、测试、启动脚本
5. 不要修改项目代码

请重点阅读以下内容：

1. `README`
2. `docs`
3. `examples`
4. `package.json` / `pyproject.toml` / `pubspec.yaml`
5. 其他能说明入口、架构或核心模块的关键文件

请输出一份中文学习笔记，至少包含：

1. 项目一句话总结
2. 它解决什么问题
3. 核心功能
4. 技术栈
5. 目录结构
6. 核心入口文件
7. 如何运行
8. 如何学习这个项目
9. 适合我借鉴什么
10. 不适合我借鉴什么

补充要求：

- 如果项目结构复杂，请按“先总体、后模块、再关键文件”的顺序讲解
- 如果官方文档不足，请明确指出哪些结论是根据代码结构推断出来的
- 尽量用面向初学者也能看懂的中文表达
