# GitHub 项目网页版 PPT 生成提示词

请帮我把这个 GitHub 开源项目做成一个网页版 PPT：

项目地址：
<在这里粘贴 GitHub 地址>

目标：
生成一个适合小白学习的可视化网页讲解页面。

请使用：

- `codebase-onboarding` skill = 代码库入门
- `code-tour` skill = 代码导览
- `documentation-lookup` skill = 文档查找
- `frontend-patterns` skill = 前端页面实现
- `design-system` 思路 = 统一视觉风格

## 第一阶段：只读分析

要求：

1. 不要安装依赖
2. 不要运行项目
3. 不要修改原项目源码
4. 只阅读 `README`、`docs`、`package.json`、`pyproject.toml`、`pubspec.yaml`、`go.mod`、`Cargo.toml` 等关键文件
5. 总结项目用途、核心功能、技术栈、目录结构、安装方式

## 第二阶段：生成 PPT 内容大纲

请把项目整理成 10 个章节：

1. 项目一句话介绍
2. 这个项目解决什么问题
3. 适合谁使用
4. 核心功能
5. 技术栈
6. 项目目录结构
7. 核心文件讲解
8. 安装和启动流程
9. 英文术语词典
10. 学习路线和下一步

要求：

- 每个英文术语后面都加中文翻译
- 每个专业词都要有小白解释
- 多用生活类比
- 不要堆术语
- 不要只复制 `README`
- 要像老师上课一样讲

## 第三阶段：生成网页文件

请创建：

```text
project-presentation/
├── index.html
└── README.md
```

`index.html` 要求：

1. 单文件 HTML，尽量少依赖外部资源
2. 像网页版 PPT，一屏一页或一节一页
3. 有清晰导航
4. 有目录树展示
5. 有卡片式信息区
6. 有英文术语词典表格
7. 视觉风格简洁现代
8. 适合浏览器直接打开
9. 支持移动端基本阅读
10. 不要引入复杂框架

`README.md` 要求：

1. 说明这个网页 PPT 是基于哪个 GitHub 项目生成的
2. 说明如何打开
3. 说明里面包含哪些章节
4. 说明后续如何重新生成

## 第四阶段：输出结果

完成后告诉我：

1. 生成了哪些文件
2. 如何打开 `index.html`
3. 这个项目最值得学习的 3 个点
4. 如果我想继续深入，下一步应该看哪些文件
