# Markdown 文档老师式讲解提示词

请帮我讲解这个项目里的 Markdown 文档：

文档路径：
<填写文档路径，比如 README.md 或 docs/README_CN.md>

项目地址：
<填写 GitHub 地址>

要求：

1. 不要只总结
2. 要像老师讲课一样逐段讲
3. 每个英文标题都翻译成中文
4. 每个专业词都翻译和解释
5. 每一节都要告诉我：
   - 原文大概说什么
   - 中文意思是什么
   - 小白怎么理解
   - 为什么这节重要
   - 实际使用时怎么做
6. 如果有命令，要逐条解释命令作用
7. 如果有表格，要解释表格每一列
8. 如果有架构图，要用文字重新解释
9. 最后整理成学习笔记

请优先使用：

- `documentation-lookup` skill = 文档查找
- `code-tour` skill = 代码导览

输出结构：

## 文档整体作用

说明这个文档是干嘛的。

## 目录结构

列出这个 Markdown 文档的章节标题，并翻译成中文。

## 逐节讲解

每一节按格式：

### 原标题：中文翻译

- 这一节在讲什么
- 小白怎么理解
- 关键词解释
- 实际怎么用
- 容易误解的地方

## 命令解释

如果文档里有命令，逐条解释：

| 命令 | 中文解释 | 什么时候用 | 风险 |
|---|---|---|---|

## 英文词汇表

| 英文 | 中文 | 小白理解 |
|---|---|---|

## 最终学习笔记

整理成适合我复习的笔记。
