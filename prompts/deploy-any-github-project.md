# 通用提示词：部署任何 GitHub 开源项目

请帮我部署一个 GitHub 开源项目。

项目地址：
<在这里粘贴 GitHub 地址>

请使用以下已安装的 Agent / Skill：

1. `codebase-onboarding` skill = 代码库入门
   用来先理解这个项目是做什么的。
2. `code-tour` skill = 代码导览
   用来讲解项目目录结构和核心文件。
3. `documentation-lookup` skill = 文档查找
   用来优先阅读 README、docs 和官方文档，不要凭记忆乱猜。
4. `build-error-resolver` agent = 构建错误修复员
   如果安装依赖、构建、启动失败，用它分析错误并做最小修复。
5. `code-reviewer` agent = 通用代码审查员
   用来检查项目结构、潜在风险和可维护性问题。
6. `security-reviewer` agent = 安全审查员
   用来检查安装脚本、依赖、危险命令、密钥和权限风险。

如果这是 Python 项目，请额外使用：

7. `python-reviewer` agent = Python 审查员
   用来分析 Python 项目结构、依赖和运行方式。

执行流程：

## 第一阶段：只读分析，不要安装依赖，不要修改文件

1. 先阅读 `README`、`docs`、`package.json`、`pyproject.toml`、`pubspec.yaml`、`requirements.txt` 等关键文件。
2. 使用 `codebase-onboarding` skill 帮我理解这个项目。
3. 使用 `code-tour` skill 给我讲项目目录结构。
4. 使用 `documentation-lookup` skill 查官方安装说明。
5. 总结以下内容：
   - 这个项目是做什么的
   - 技术栈是什么
   - 支持哪些平台
   - 官方推荐安装方式
   - 启动命令
   - 测试命令
   - 构建命令
   - 常见风险点

## 第二阶段：环境检查

请先检查我的本机环境，不要直接安装：

1. 操作系统
2. CPU 架构
3. Python / Node / Flutter / Go 等版本
4. `git` 是否安装
5. 包管理器是否安装
6. 项目要求的系统依赖是否安装
7. 当前目录是否适合 clone 项目

## 第三阶段：安装计划

请输出安装计划：

1. 会执行哪些命令
2. 每条命令的作用
3. 哪些命令可能耗时较长
4. 哪些命令可能需要网络
5. 是否需要国内镜像
6. 是否会修改系统环境
7. 是否有高风险命令

等我确认后再执行。

## 第四阶段：执行安装

确认后再执行：

1. `clone` 项目
2. 安装系统依赖
3. 安装项目依赖
4. 启动项目
5. 如果失败，复制关键错误信息
6. 使用 `build-error-resolver` agent 分析错误
7. 使用最小修改或最小命令修复
8. 修复后重新验证

## 第五阶段：交付结果

完成后输出一份中文部署笔记：

1. 项目用途
2. 安装步骤
3. 实际执行的命令
4. 遇到的问题
5. 解决方式
6. 启动方式
7. 常用命令
8. 卸载 / 清理方式
9. 后续学习建议

安全要求：

- 不要凭记忆乱猜，优先依据项目 `README` 和官方文档
- 不要执行危险命令
- 不要读取 `.env`、私钥、`token` 文件
- 不要安装 CUDA / GPU 相关内容，除非我明确要求
- 如果需要 API Key，先停下来问我
- 如果连续失败 3 次，停止并总结原因
